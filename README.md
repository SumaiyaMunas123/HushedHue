# Hushed Hue

Flagship site for **Hushed Hue** — colour, softly spoken.

## Stack

Next.js 15 (App Router), TypeScript, Tailwind CSS v4, Motion, Lenis, GSAP ScrollTrigger, OGL.

See [DESIGN.md](./DESIGN.md) and [ARCHITECTURE.md](./ARCHITECTURE.md).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Optimized for [Vercel](https://vercel.com). Connect the repo and deploy with default settings.
